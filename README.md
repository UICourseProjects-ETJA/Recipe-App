# Recipe CRUD App 🍽️

This project is a simple **recipe-tracking CRUD application** built with **React**. It allows users to create, view, and delete recipes using local component state.

The app was built as part of a Ui Course assessment, that focuses on **state management, components, and forms**.

---

## ✨ Features

- Add new recipes with:
  - Name
  - Cuisine
  - Photo URL
  - Ingredients
  - Preparation instructions
- Display recipes in a structured table layout
- Delete individual recipes
- Scrollable content for long ingredients and preparation text
- Responsive image handling using `object-fit`
- Styled to closely match a provided design mockup

---

## 🛠️ Tech Stack

- **React**
- **JavaScript (ES6+)**
- **CSS**
- React Hooks (`useState`)
